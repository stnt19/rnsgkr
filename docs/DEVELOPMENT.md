# 질문·답변 챗봇 개발 문서

## 구성

| 파일 | 역할 |
| --- | --- |
| `server.py` | 로컬 HTTP 서버·질문 검증·질의응답 라우팅 |
| `maintenance.py` | 부품명 검색·정비 안내·원문 및 그림 렌더링 |
| `service_guides.py` | 교범 버전·페이지 근거 검사와 검토 요약 구성 |
| `data/service-guides.json` | 13종 부품의 설명·점검·정비·주의사항·그림 범위 |
| `data/parts.json` | 부품 ID·별칭·SGN·문서 및 페이지 연결 |
| `web/app.js` | 질문 전송·답변 및 그림 표시·원문 모달·참고 문서 |
| `web/style.css`, `web/guides.css` | 반응형 채팅 화면과 정비 안내 스타일 |
| `scripts/import_manuals.py` | 허가된 로컬 PDF의 선별 색인 생성 |

질문 입력과 답변 표시가 기본 화면입니다. 카메라·비전 모듈, 모델 가중치 설정, 영상 스트림·프레임 전송과 이미지 인식 API는 제거했습니다. 답변의 사진은 교범 내부의 검토된 그림을 표시하는 기능입니다.

## API

| 메서드·경로 | 용도 |
| --- | --- |
| `POST /api/chat` | 질문과 최근 대화로 답변 생성 |
| `GET /api/parts` | 부품 목록과 색인 쪽수 |
| `GET /api/part?id=battery` | 해당 부품의 페이지 및 공통 주의사항 |
| `GET /api/manuals` | 교범 목록·쪽수·가용 여부; 로컬 절대 경로는 제외 |
| `GET /manual-page?doc=engine&page=572` | 원본 페이지 PNG |
| `GET /manual-figure?part=battery&figure=location` | 고정된 허용 영역의 교범 그림 PNG |
| `GET /document?doc=engine` | 등록된 로컬 교범 PDF |

질문 요청은 `question` 문자열과 선택적 `history`, `partId`입니다. 질문은 1~2,000자, 전체 본문은 24,000바이트 이하입니다. `history`는 최대 12개 메시지이며 각 `content`는 4,000자 이하입니다. UI는 최근 메시지 6개를 전송합니다. 정비용 `partId`는 API 호환을 위해 유지하지만 UI에서 별도 부품 선택을 요구하지 않습니다.

응답은 `answer`, `sources`, `mode`, 선택적 `notice`를 포함합니다. 검토된 정비 안내는 `presentation: "service-guide"`와 `guide`를 추가합니다. `guide`는 설명, 점검 및 정비 단계, 주의사항, 그림, 추가 확인 질문으로 구성됩니다. 원문은 기본 답변에 복사하지 않고 필요 시 출처 모달에서 열 수 있습니다.

정비 출처의 `id`는 `문서ID:PDF쪽`이며 각 문장의 `refs`와 대응합니다. `answer`는 같은 요약의 텍스트 버전으로 대화 이력에 사용합니다. 사용자가 명시한 부품명·별칭·SGN으로 부품을 찾고 지원하는 후속 질문에는 이전 부품 문맥을 활용합니다. 일반 증상만으로 모든 고장을 진단하는 기능은 아닙니다.

## 자료와 그림

교범 원본은 기존 로컬 경로에 두고 가져오기 시 경로·쪽수·SHA-256을 등록합니다. 생성한 `*.local.json`, PDF, 임시 이미지는 Git 추적에서 제외됩니다. 파일을 옮기거나 교체하면 다시 가져오고 서버를 재시작합니다.

요약은 가져온 교범의 SHA-256 메타데이터와 필요한 근거 페이지를 검사합니다. 원본 파일 전체의 해시를 매 요청마다 다시 계산하지는 않습니다. 버전·페이지가 맞지 않으면 검토 요약을 제공하지 않습니다. 규정값과 전체 선행/후속 작업은 원문 확인이 필요합니다.

그림 API는 등록된 부품·그림 ID만 받고 사용자가 지정한 파일 경로나 자르기 좌표는 받지 않습니다. PDF 렌더링 후 검토된 영역을 잘라 표시하며 서버 메모리에 최대 32개를 캐시합니다. 원본 전체와 캡션·페이지를 연결하고, 그림 로딩 실패 시 원문 열기로 대체합니다.

## 실행·검증


```powershell
python -m unittest discover -s tests -v
```

서버는 `127.0.0.1`에만 바인딩합니다. 대화는 브라우저 메모리에만 보관하며 새 대화·새로고침에서 초기화됩니다. 인증·TLS·운영용 접근 제어·다중 사용자 격리는 별도 구현 사항입니다.


### 질문 범위 및 근거 확인 (2026-10-30)

- 차량 정비·검토된 제작사 공식 정보 외 질문: 범위 밖 안내 (`reason: out-of-scope`).
- 차량 관련이지만 검토된 안내로 답할 수 없는 질문: 근거 부족 안내 (`reason: missing-evidence`). 두 경우 모두 출처와 정비 안내를 생성하지 않습니다.
- 부품명·SGN만 일치한다고 안내하지 않습니다. 질문 전체가 일반 설명·위치·점검·교환 등 허용된 요청 형태인지 확인합니다. 헤드램프 결로는 별도로 검토된 안내를 사용합니다.
- 미검토 수치·가격, 교환 주기, 미검토 증상, 다른 부품을 섞은 질문은 추측하지 않습니다. 정비 PDF 전체를 의미적으로 판정하는 모델이 아니라 보수적인 규칙 방식이므로, 표현이 낯설면 근거 부족으로 처리될 수 있습니다.


### 제작사 공식 정보

- `data/official-info.json`에 원문을 검토한 사실만 등록하고 `official_info.py`에서 질문 범위를 확인합니다. 이번에 등록한 자료는 KGM 공식블로그의 2023년 트림 개편 가격 및 2025 모델 출시 가격입니다.
- `/api/official-sources`는 참고 문서용 공식 자료 목록, `/api/status`는 공식 자료 수를 제공합니다.
- 각 자료에는 공식 URL, 제작사명, 확인일(한국 시간), 대상 모델 연도, 2023년형 해당 여부와 조건을 저장합니다. 확인일을 서버 실행일로 자동 갱신하지 않습니다.
- 2023년 트림 개편 게시물은 조건부 참고 자료이며 개별 차량의 생산 시점·변속기·옵션까지 확정하지 않습니다. 2025 자료는 2023년형에 해당하지 않습니다.
- 현재가, 중고가, 미검토 부품 가격, 다른 모델·연식과 혼합된 질문에는 과거 가격을 대신 적용하지 않습니다.
- 질문 시 외부 검색을 실행하지 않습니다. 관리자가 제작사 원문을 검색·검토한 뒤 데이터와 확인일을 함께 갱신하고 서버를 재시작합니다. 검색 요약만으로 등록하지 않습니다.
- 답변 `mode: official`과 출처 `kind: official`을 지원합니다. 원문 링크와 확인일, 연식 적용 조건을 답변 및 참고 문서에 표시합니다.
- 차량 교범과 공식 자료만 공개합니다. 기존 내부 문서 검색·모델 호출 및 `/api/pages`, 매개변수 없는 `/document` 경로는 제거했습니다.


### 부품명 유사 검색 (2026-10-31)

- 등록된 이름·별칭·SGN의 정확 일치를 먼저 사용하고, 일치하지 않으면 `part_matching.py`가 이름·별칭과 입력 부품명의 편집 거리를 비교합니다. 숫자 SGN은 오타 보정하지 않습니다.
- 후보가 하나로 구분될 때만 입력의 부품명 구간을 공식 부품명으로 바꿉니다. 조사·증상·수치·질문 의도는 유지하고, 보정된 질문 전체를 기존 `question_scope.supported` 검사에 통과시킨 뒤 교범 근거를 조회합니다.
- 예: `헤드렘프에 결로가 계속 생겨요`, `베터리 점검 방법`, `에어컨 필타 교환 방법`. 답변 아래에 입력 부품명과 해석된 부품명을 표시합니다.
- 여러 후보의 유사도가 비슷하거나 `필터`처럼 이름이 불완전하면 `reason: ambiguous-part`와 후보 목록을 반환합니다. 후보를 하나 골라 부품명을 포함해 다시 질문할 수 있습니다.
- API 응답의 `partMatch`에는 `inputName`, `matchedName`, `normalizedQuestion`, `partId`가 포함됩니다. UI는 기존 `notice` 영역으로 보정 사실을 표시합니다.
- 후속 질문은 이전 질문을 다시 보정·검증하며 결로 등 기존 질문의 조건을 유지합니다. `partId`로 다른 부품을 강제하거나 이전의 근거 부족 질문을 일반 정비 안내로 바꿀 수 없습니다.
- 유사도와 허용 질문 형태를 사용하는 규칙 방식입니다. 모든 표현의 의미나 사실적 무오류를 판정하는 기능은 아니며, 미검토 수치·증상·혼합 질문은 계속 거절합니다.


### 상세 증상 없는 작동 이상 안내 (2026-10-31)

- `와이퍼가 작동하지 않는다`, `헤드램프가 작동이 이상해요`, `배터리가 고장 났어요`처럼 부품과 짧은 이상 표현만 있어도 기본 점검·관련 정비 개요를 제공합니다. 추가 증상 응답은 필수가 아닙니다.
- 적용 대상은 검토된 교범 안내가 등록된 13종 부품입니다. 미등록 부품, 근거 없는 수치·특정 진단, 서로 다른 부품을 섞은 질문에는 검증되지 않은 절차를 생성하지 않습니다.
- 기본 점검을 먼저 보여 주고, 탈거·교환은 점검 후 필요성이 확인된 경우의 작업으로 구분합니다. 답변 첫 부분에 확정 진단이 아니라는 범위를 표시합니다.
- 프런트 와이퍼를 신규 등록했습니다. 정비지침서 상 PDF 281~321쪽을 색인하며, 요약에는 282~284·313~321쪽 중 검토된 내용만 사용합니다. 동결·마모·레인센서 확인, 블레이드·암·모터/링케이지 작업과 선행 작업·파킹 정렬 주의사항을 포함합니다.
- 기존 환경에서는 새 `data/parts.json`을 기준으로 교범 가져오기를 다시 실행하고 서버를 재시작해야 와이퍼 원문·그림을 사용할 수 있습니다. 원문·로컬 색인은 Git에 포함하지 않습니다.


### 부품 가격 안내 (2026-10-31)

- `part_prices.py`와 `data/part-prices.json`에서 제작사 공식 순정부품 조회 결과를 검토한 가격을 관리합니다. 렉스턴스포츠 모델 코드 U로 확인한 12개 부품군의 일부 품번을 등록했습니다. 차량 판매가와 분리하여 조회합니다.
- `와이퍼 모터 가격`, `배터리 가격`, `헤드라이트 오른쪽 가격`, `에어컨 필터 가격`을 지원합니다. 와이퍼 블레이드·암·모터·링케이지 및 좌우를 구분합니다. 부품 질문 뒤 `가격은?`도 지원합니다.
- 가격에는 품번·정식 품명·확인일·공식 링크를 붙이고 부가세 미포함, 공임·배송비·추가 부품 별도임을 표시합니다. 교환 비용 질문에도 부품값을 총 정비비로 표현하지 않습니다.
- 공식 조회는 차종 단위이며 연식별 적용 정보가 없으므로 **2023년형 적용 미확정**입니다. 특정 차량의 호환·최저가·전체 품번 목록을 보장하지 않습니다. 에어클리너 어셈블리 가격을 필터 엘리먼트 가격으로 대체하지 않습니다.
- 질문마다 외부 조회하지 않습니다. 가격 갱신은 https://www.kg-mobility.com/sr/service-network/search-parts 에서 렉스턴스포츠와 부품 번호를 선택해 원문 값을 재검토한 뒤 금액·확인일을 함께 수정합니다. 조회 가격은 VAT 미포함입니다.
- 공식 자료 목록 `/api/official-sources`에 부품 가격도 표시합니다. 가격 미등록·미검토 세부 품목은 가격을 추측하지 않고 정확한 품번 확인을 안내합니다. 차종·부품명 없이 가격만 물으면 대상을 확인합니다.
