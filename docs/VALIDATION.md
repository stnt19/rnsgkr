## 부품 목록 확장 당시 자동 테스트

`python scripts/run_tests.py`로 총 95개 테스트가 통과했습니다. 전체 406개 항목과 4,771개 레코드를 순회하는 하위 검사도 포함합니다. PDF를 가져오지 않은 환경에서는 로컬 교범 검사가 건너뛰어집니다. JavaScript 문법 검사와 git diff 공백 검사도 통과했습니다.

공식 가격 테스트: PDF 미등록 부품, 품번, 이름 순서, 차종 필터, 좌우, 잘못된 금액·응답, 타임아웃, 응답 크기, 페이지 상한, 중복 품번, 캐시 시각·만료, 과거 자료 대체, 미등록 부품 후속 가격 질문을 모의 응답으로 검증합니다.

## 실연결 확인

KGM 공식 공개 부품 API에서 오일 펌프, 와이퍼 모터, 와셔 노즐의 품명·품번·가격 반환을 확인했습니다. 복합 품명이 공식 품명과 단어 순서가 달라 검색되지 않던 문제를 수정했습니다. 이 검사는 2023년형 개별 차량의 호환성을 검증한 것이 아닙니다.

재시작한 HTTP 서버에서 `/api/parts`의 406개·4,771쪽, 오일 펌프·제동·공조 답변, 와셔 노즐 공식 가격, 엔진 PDF 497쪽 이미지(HTTP 200)를 확인했습니다. 브라우저 도구가 최소화된 Chrome 창을 복원하지 못하여 이번 변경의 실제 화면 육안 검증은 완료하지 못했습니다.

배선도는 후속 OCR 작업으로 검색에 연결했으며 [OCR 검증 기록](WIRING_OCR.md)을 참고하세요. 원문 참고 답변은 발췌이며 모든 작업의 선행·후속 절차를 검증한 상세 요약은 아닙니다. 전체 페이지의 시각 검수 또는 모든 사용자 질문에 대한 의미 정확도를 보장하는 검사는 아닙니다.
