# 렉스턴 스포츠 2023 자료 선별

## 등록 및 제외 기준

사용자가 지정한 PDF 7개, 총 5,728쪽의 문서 수·페이지 수·목차 및 대상 부분을 확인했습니다. 모든 페이지의 정비 내용을 전수 검수한 것은 아닙니다. 대상 부품의 개요·위치·구성, 관련 시스템 점검, 탈거·장착과 공통 주의사항을 선별하여 171쪽의 본문을 로컬 색인으로 생성했습니다.

| 자료 | 전체 쪽수 | 이번 사용 |
| --- | ---: | --- |
| 엔진 | 1,072 | 8종 부품 및 관련 계통 점검·주의사항 |
| 새시 | 930 | 원본 등록; 구동·조향·제동은 초기 대상 제외 |

카탈로그 그룹 검색은 공백 제거 후 제목·별칭 일치 방식이며, 해당 품번의 실제 차량 적용 여부를 검증한 결과가 아닙니다. 매칭되지 않은 부품에는 링크를 만들지 않습니다. SGN과 주문 품번을 혼용하지 않습니다. 전기배선도는 후속 OCR·도면 검수 후 검색에 포함해야 합니다.

## 데이터 생성과 보관

`scripts/import_manuals.py`는 고정된 허용 파일명 7개를 읽고, `data/parts.json`의 범위와 공통 주의사항만 추출합니다. 카탈로그는 페이지 제목을 순회하여 관련 그룹을 찾습니다. 공백·그림 중심의 짧은 텍스트 페이지는 본문 색인에서 제외될 수 있으나 원본 페이지는 열 수 있습니다.

생성 파일은 모두 `.gitignore`에 포함됩니다.

- `manuals.local.json`: 원본 절대 경로·쪽수·SHA-256·선별 상태
- `manual-index.local.json`: 선택한 원문·인쇄 번호·부품 연결·카탈로그 참조
- `manual-import-report.local.json`: 전체 쪽수·색인 쪽수·매칭 수

원본을 변경·이동한 경우 다시 가져오고 서버를 재시작해야 합니다. SHA-256은 가져오기 시 변경 비교용 메타데이터이며 서버가 매 요청마다 원본 해시를 재검증하지는 않습니다.

## 질문·답변의 현재 범위

사용자가 부품명과 증상을 입력하면 해당 부품의 검토된 설명·점검·정비 작업 개요와 교범 그림을 보여 줍니다. 카메라와 자동 부품 인식 기능은 제거했습니다. 부품 사진은 정비교범의 위치·구성 도해를 뜻합니다.

정비 안내는 원문 근거가 있는 요약이며, 모든 고장에 대한 문답형 진단 트리나 센서 측정 기반 확정 진단은 아닙니다. 부품별 질문 정답셋과 전문가 검토를 통해 안내 범위를 확장할 수 있습니다.


### 상세 증상 없는 작동 이상 안내 (2026-10-31)

- `와이퍼가 작동하지 않는다`, `헤드램프가 작동이 이상해요`, `배터리가 고장 났어요`처럼 부품과 짧은 이상 표현만 있어도 기본 점검·관련 정비 개요를 제공합니다. 추가 증상 응답은 필수가 아닙니다.
- 적용 대상은 검토된 교범 안내가 등록된 13종 부품입니다. 미등록 부품, 근거 없는 수치·특정 진단, 서로 다른 부품을 섞은 질문에는 검증되지 않은 절차를 생성하지 않습니다.
- 기본 점검을 먼저 보여 주고, 탈거·교환은 점검 후 필요성이 확인된 경우의 작업으로 구분합니다. 답변 첫 부분에 확정 진단이 아니라는 범위를 표시합니다.
- 프런트 와이퍼를 신규 등록했습니다. 정비지침서 상 PDF 281~321쪽을 색인하며, 요약에는 282~284·313~321쪽 중 검토된 내용만 사용합니다. 동결·마모·레인센서 확인, 블레이드·암·모터/링케이지 작업과 선행 작업·파킹 정렬 주의사항을 포함합니다.
- 기존 환경에서는 새 `data/parts.json`을 기준으로 교범 가져오기를 다시 실행하고 서버를 재시작해야 와이퍼 원문·그림을 사용할 수 있습니다. 원문·로컬 색인은 Git에 포함하지 않습니다.
