## 대조 방법

`scripts/review_manual_registry.py`는 목차의 부품명과 작업 코드(SGN)를 해당 장의 본문과 대조합니다. 동일 이름은 여러 원문 위치를 보존합니다. 조향장치·계기판은 사양별 원문 범위를 함께 등록합니다. 기존 상세 안내의 ID와 별칭은 유지합니다.

동일 SGN이 반복되거나 목차와 본문의 코드가 다른 항목은 확인한 PDF 페이지를 별도 anchor로 지정했습니다. 셀렉터 포지션 스위치, 수동변속기 오버홀, 숏/롱 데크 프로펠러 샤프트, 리프 주차 브레이크 슈, 리어 디퍼렌셜 캐리어 등이 해당합니다. SGN은 부품 구매용 품번이 아닙니다.

목차 항목 5개는 직접 연결을 확정하지 않았습니다: 암 전류, CCA, ISG 장의 콘솔 스위치, 두 조향장치 장의 점검 항목. 이들은 전체 텍스트·관련 시스템 범위에서 검색할 수 있지만 부정확한 독립 부품 링크를 생성하지 않습니다. 상세 결과는 Git에서 제외한 `data/manual-audit.local.json`에 저장합니다.

## 재생성과 버전 관리

신규 설치: `python scripts/import_manuals.py --directory '<원본 폴더>'`.

목록 재검토: 전체 추출 후 `python scripts/review_manual_registry.py`, 이어서 `python scripts/index_full_manuals.py`, 테스트 실행 및 서버 재시작.

원본 fingerprint가 로컬 manifest와 다르면 전체 색인 작업을 중단합니다. 등록 범위는 검토된 sourceHash와 일치할 때만 연결합니다. 상세 안내도 원문 버전·필요 페이지를 검사합니다. PDF가 교체되면 이름이 같더라도 목록과 상세 안내를 다시 검토해야 합니다.

원문 전문·로컬 절대 경로·그림은 저장소에 넣지 않습니다. 추적하는 것은 이름, 별칭, 문서 ID, 페이지 범위, 검토된 요약과 해시입니다.
