# 배선도 OCR·원본 대조 기록 · 2026-10-31

## 처리 결과

- 원본 배선도 796쪽 전체를 Windows.Media.Ocr 한국어 엔진으로 로컬 처리했습니다. 외부 전송이나 원본 PDF 변경은 없습니다.
- 검색 내용이 있는 766쪽을 추가하여 전체 교범 검색은 5,537쪽입니다.
- 66쪽은 OCR과 비교 가능한 원문 텍스트를 글꼴로 복원했고, 141쪽은 일부 문구를 대조했습니다. 나머지 559쪽은 OCR 참고 검색입니다. 글꼴 대조는 도면 전체의 연결 관계를 확인했다는 뜻이 아닙니다.
- 회로 식별 기호와 와이퍼 모터·스위치, 레인센서, 2-램프/4-램프 헤드 램프의 6개 안내는 원본 사진·표를 직접 확인하여 별도로 작성했습니다.

## 글자 깨짐과 보정 방법

문제 페이지의 일부 글꼴은 `/Identity-H` 및 `/CIDToGIDMap /Identity`를 사용하면서 `/ToUnicode`가 없습니다. 일반 추출은 glyph ID를 문자처럼 반환했습니다. OCR에서는 한국어를 읽을 수 있지만 SB11/SBII, 10A/1 OA, IGN1/IGNI 등 오류가 확인됐습니다.

`check_wiring_glyphs.py`는 PDF 내장 글꼴과 설치된 동일 계열 글꼴의 개별 윤곽 좌표·윤곽 끝점·플래그가 정확히 일치하고 Unicode 후보가 하나인 경우에만 문자를 복원합니다. 글꼴 이름·고정 문자 오프셋만으로 치환하지 않습니다. 페이지 영역 밖의 숨은 글자는 제외합니다. 문자로 저장되지 않은 도면 내부는 복원할 수 없어 OCR을 사용합니다.

복원된 원문 텍스트의 양이 OCR 텍스트 대비 충분한 페이지는 복원 텍스트를 사용하고, 나머지는 유일하게 대응하는 긴 문구만 보정합니다. 별도 숫자·단자 식별자는 유사하다는 이유로 바꾸지 않습니다. 원문 글꼴로 읽은 텍스트와 추가 OCR 문구를 구분해 보관합니다. 그림의 선 연결·좌우 방향·표의 열 관계는 자동 추론하지 않습니다.

## 원본 이미지와의 표본 대조

직접 렌더링해 확인한 PDF 페이지: **5, 7, 100, 300, 500, 625, 626, 700, 783, 789**.

선정한 문구·식별자·핀 표 항목 76개에서 원시 OCR 53개, 보정 후 76개가 일치했습니다. 이 중 중요 기호·핀 표 항목 25개도 보정 후 모두 일치했습니다. 이는 **선정된 문자열의 포함 여부 검사**이며 전체 문자의 정확도, 단어 오류율 또는 796쪽 전체의 정답률이 아닙니다. 기준은 `data/wiring-ocr-checks.json`, 로컬 상세 결과는 `data/wiring-ocr-validation.local.json`입니다.

원본 표에서 확인한 차이의 예: 4-램프 헤드 램프의 5번은 로우 빔 접지지만, 2-램프 표의 5번은 `-`이고 6번이 로우/하이 빔 접지입니다. 질문에 사양이 없으면 두 사양을 따로 보여 줍니다. 와이퍼 모터의 단품 측·와이어링 측 사진 방향도 함께 확인하도록 합니다.

## 재현·검증

```powershell
python -m pip install -r requirements.txt
python scripts/ocr_wiring.py
python scripts/check_wiring_glyphs.py
python scripts/validate_wiring_ocr.py
python scripts/index_full_manuals.py
python scripts/run_tests.py
```

Windows 한국어 OCR 언어가 필요합니다. 글꼴 대조 기본값은 `C:/Windows/Fonts/gulim.ttc`이며 `--font`로 다른 경로를 지정할 수 있습니다. 다른 환경에서 복원에 실패하면 검증된 것으로 표시하지 않습니다. 원본 SHA-256 불일치·미완료 OCR·중복/누락 페이지·잘못된 엔진 정보는 색인하지 않습니다. 검토 요약도 해당 원본 해시와 페이지의 기준 문구가 맞을 때만 사용합니다.

전체 OCR, 단어 좌표, 복원 전문, 검증 상세, 임시 렌더 이미지는 Git에서 제외합니다. 다른 PC에서는 원본 PDF로 재생성해야 합니다.

## 실행 확인

회귀 테스트 115개와 표본 비교 검사 76개가 통과했습니다. 실제 HTTP 서버에서 와이퍼 모터 핀 맵(625쪽), 헤드 램프 사양별 핀 맵(783·789쪽), 일반 배선도 검색과 원본 이미지(HTTP 200)를 확인했습니다. 원본 PDF의 SHA-256이 처리 전과 같음도 확인했습니다.
