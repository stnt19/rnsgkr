# 정비온 · 렉스턴 스포츠 정비 지식 챗봇

질문을 입력하면 렉스턴 스포츠 2023 교범을 바탕으로 부품 설명, 점검 사항, 주의사항, 정비 작업 흐름과 사진·도해를 보여 주는 로컬 웹 챗봇입니다. 현재 12종 부품·원문 130쪽을 선별해 연결했습니다. 카메라·사진 업로드·비전 인식 기능은 제거했습니다.

## 실행

Python 3.10 이상을 사용합니다.

```powershell
python -m pip install -r requirements.txt
python scripts/import_manuals.py --directory '정비 PDF 7개가 들어 있는 폴더의 절대 경로'
python server.py
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 이미 자료를 가져왔다면 서버만 실행하면 됩니다. 서버는 루프백에서만 동작하며, 포트는 `PORT` 환경변수로 바꿀 수 있습니다. 종료는 실행 터미널에서 Ctrl+C입니다.

## 사용

- 부품명과 궁금한 내용을 함께 질문합니다. 예: `배터리 점검 방법`, `에어컨 필터 교환`, `헤드램프 결로가 계속 생겨요`.
- 답변 안의 사진이나 원문 버튼을 누르면 해당 교범 페이지를 확인할 수 있습니다.
- 새 대화는 화면의 대화 이력을 초기화합니다. 참고 문서에서 연결된 교범 목록을 확인합니다.

현재 안내는 검토된 교범 요약이며, 모든 증상과 고장 코드를 새로 진단하는 기능은 아닙니다. 헤드 램프 결로·습기는 별도 흡습제 안내를 제공합니다. 규정값·차량 사양·전체 선행/후속 작업은 원문을 대조해야 합니다.

## 자료와 답변

`data/service-guides.json`과 `service_guides.py`가 부품별 설명·단계·주의사항·그림 범위와 페이지 근거를 관리합니다. 교범 버전의 SHA-256 메타데이터가 검토 버전과 다르거나 근거 페이지가 누락되면 요약을 제공하지 않습니다. 원본을 바꾼 경우 다시 가져오고 서버를 재시작하세요.

교범 원본은 원래 로컬 경로에 보관합니다. `data/manuals.local.json`, `data/manual-index.local.json`, `data/manual-import-report.local.json`, 원본 PDF와 임시 이미지는 Git에서 제외합니다. 다른 PC에서는 허가된 PDF를 준비해 다시 가져와야 차량 교범 안내·사진이 동작합니다. 원본 파일과 추출 전문은 저장소에 포함하지 않습니다.

기본 기능에는 AI API 키가 필요하지 않습니다. 대화는 브라우저 메모리에만 유지합니다.

### 질문 범위 및 근거 확인 (2026-10-30)

- 차량 정비·검토된 제작사 공식 정보 외 질문: 범위 밖 안내 (`reason: out-of-scope`).
- 차량 관련이지만 검토된 안내로 답할 수 없는 질문: 근거 부족 안내 (`reason: missing-evidence`). 두 경우 모두 출처와 정비 안내를 생성하지 않습니다.
- 부품명·SGN만 일치한다고 안내하지 않습니다. 질문 전체가 일반 설명·위치·점검·교환 등 허용된 요청 형태인지 확인합니다. 헤드램프 결로는 별도로 검토된 안내를 사용합니다.
- 미검토 수치·가격, 교환 주기, 미검토 증상, 다른 부품을 섞은 질문은 추측하지 않습니다. 정비 PDF 전체를 의미적으로 판정하는 모델이 아니라 보수적인 규칙 방식이므로, 표현이 낯설면 근거 부족으로 처리될 수 있습니다.


### 제작사 공식 정보

- `data/official-info.json`에 원문을 검토한 사실만 등록하고 `official_info.py`에서 질문 범위를 확인합니다. 이번에 등록한 자료는 KGM 공식블로그의 2023년 트림 개편 가격 및 2025 모델 출시 가격입니다.
- `/api/official-sources`는 참고 문서용 공식 자료 목록, `/api/status`는 공식 자료 수를 제공합니다.
- 각 자료에는 공식 URL, 제작사명, 확인일(한국 시간), 대상 모델 연도, 2023년형 해당 여부와 조건을 저장합니다. 확인일을 서버 실행일로 자동 갱신하지 않습니다.
- 2023년 트림 개편 게시물은 조건부 참고 자료이며 개별 차량의 생산 시점·변속기·옵션까지 확정하지 않습니다. 2025 자료는 2023년형에 해당하지 않습니다.
- 현재가, 중고가, 미검토 부품 가격, 다른 모델·연식과 혼합된 질문에는 과거 가격을 대신 적용하지 않습니다.
- 질문 시 외부 검색을 실행하지 않습니다. 관리자가 제작사 원문을 검색·검토한 뒤 데이터와 확인일을 함께 갱신하고 서버를 재시작합니다. 검색 요약만으로 등록하지 않습니다.
- 답변 `mode: official`과 출처 `kind: official`을 지원합니다. 원문 링크와 확인일, 연식 적용 조건을 답변 및 참고 문서에 표시합니다.
- 차량 교범과 공식 자료만 공개합니다. 기존 내부 문서 검색·모델 호출 및 `/api/pages`, 매개변수 없는 `/document` 경로는 제거했습니다.


### 부품명 유사 검색 (2026-10-31)

- 등록된 이름·별칭·SGN의 정확 일치를 먼저 사용하고, 일치하지 않으면 `part_matching.py`가 이름·별칭과 입력 부품명의 편집 거리를 비교합니다. 숫자 SGN은 오타 보정하지 않습니다.
- 후보가 하나로 구분될 때만 입력의 부품명 구간을 공식 부품명으로 바꿉니다. 조사·증상·수치·질문 의도는 유지하고, 보정된 질문 전체를 기존 `question_scope.supported` 검사에 통과시킨 뒤 교범 근거를 조회합니다.
- 예: `헤드렘프에 결로가 계속 생겨요`, `베터리 점검 방법`, `에어컨 필타 교환 방법`. 답변 아래에 입력 부품명과 해석된 부품명을 표시합니다.
- 여러 후보의 유사도가 비슷하거나 `필터`처럼 이름이 불완전하면 `reason: ambiguous-part`와 후보 목록을 반환합니다. 후보를 하나 골라 부품명을 포함해 다시 질문할 수 있습니다.
- API 응답의 `partMatch`에는 `inputName`, `matchedName`, `normalizedQuestion`, `partId`가 포함됩니다. UI는 기존 `notice` 영역으로 보정 사실을 표시합니다.
- 후속 질문은 이전 질문을 다시 보정·검증하며 결로 등 기존 질문의 조건을 유지합니다. `partId`로 다른 부품을 강제하거나 이전의 근거 부족 질문을 일반 정비 안내로 바꿀 수 없습니다.
- 유사도와 허용 질문 형태를 사용하는 규칙 방식입니다. 모든 표현의 의미나 사실적 무오류를 판정하는 기능은 아니며, 미검토 수치·증상·혼합 질문은 계속 거절합니다.
