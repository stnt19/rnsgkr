# 정비온 · 렉스턴 스포츠 정비 지식 챗봇

2023년형 렉스턴 스포츠 정비교범에서 부품·시스템을 검색하고, 제작사 공식 부품 가격을 조회하는 로컬 웹 앱입니다. 7개 PDF 5,728쪽을 재추출했으며, 406개 부품·시스템 항목과 검색 가능한 5,537쪽(배선도 OCR 766쪽 포함)을 연결했습니다.

## 실행

Python 3.10 이상이 필요합니다.

```powershell
python -m pip install -r requirements.txt
python scripts/import_manuals.py --directory '정비 PDF 7개가 들어 있는 폴더의 절대 경로'
python server.py
```

[로컬 웹페이지](http://127.0.0.1:8000)를 엽니다. 기존 자료를 가져온 환경에서는 `python scripts/index_full_manuals.py`로 전체 색인을 재구성한 뒤 서버를 재시작합니다. 원본 PDF는 원래 로컬 경로에 유지합니다.

## 답변 방식

- **상세 안내**: 검토된 13종 부품의 설명·점검·정비 개요·주의사항·사진을 제공합니다.
- **원문 참고**: 나머지 부품과 구체적인 증상·수치 질문은 관련 페이지의 발췌와 원문 링크를 제공합니다. 검색 결과를 확정 진단, 완성된 정비 절차 또는 검증된 규정값으로 표현하지 않습니다.
- **공식 부품 가격**: PDF 등록 여부와 관계없이 KGM 순정부품 조회를 사용합니다. 정식 품명·품번·금액·확인 시각·공식 출처와 **2023년형 호환 미확정**을 표시합니다. 부가세·공임·배송비는 별도입니다.

예: `오일 펌프 내용 있어?`, `브레이크가 작동하지 않는다`, `에어컨 찬바람이 안 나와요`, `와셔 노즐 가격`, `6711800701 가격`.

참고 문서 화면에서 전체 부품 목록을 검색할 수 있습니다. 유사 부품명은 후보가 구분되는 경우에만 보정하고 보정 사실을 표시합니다. 여러 부품을 함께 물으면 최대 3개 항목의 원문을 나누어 안내합니다.

## 출처와 범위

배선도 796쪽은 한국어 OCR로 처리하고 검색 내용이 있는 766쪽을 답변에 연결합니다. OCR 단독 결과, 원문 글꼴 대조 결과, 원본 사진·표를 직접 검토한 핀 맵을 구분하며 원본 그림을 함께 표시합니다. 부품 카탈로그는 구성·품명 참고용이며 품번의 연식·옵션 호환이나 정비 절차를 자동 확정하지 않습니다. 전체 페이지의 텍스트·목차·부품 연결 구조를 재검토한 것이며, 모든 정비 작업을 사람이 다시 요약·검증한 것은 아닙니다.

가격은 [KGM 공식 순정부품 조회](https://www.kg-mobility.com/sr/service-network/search-parts)의 렉스턴스포츠 차종(U) 결과입니다. 질문마다 조회하되 같은 검색어는 최대 15분 캐시합니다. 확인 시각은 실제 조회 시각이며 캐시 이용 시 갱신하지 않습니다. 최대 3페이지를 검색하고 일치 후보 20개까지 표시합니다. 조회 실패나 결과 없음 시 검토된 저장 가격이 있으면 과거 확인일을 명시해 제공하고, 없으면 임의 가격을 만들지 않습니다. 정확한 품번으로 검색하면 더 좁힐 수 있습니다.

차량 판매 가격은 별도로 검토한 2023·2025년 자료를 사용하며 현재 판매가로 표현하지 않습니다. 앱에는 차량 교범·공식 정보만 표시합니다.

## 배선도 OCR 생성 (Windows)

Windows 한국어 OCR 언어가 설치되어 있어야 합니다. PDF는 외부 서버로 보내지 않으며 원본 파일도 변경하지 않습니다.

```powershell
python scripts/ocr_wiring.py
python scripts/check_wiring_glyphs.py
python scripts/validate_wiring_ocr.py
python scripts/index_full_manuals.py
python server.py
```

첫 명령은 796쪽을 처리하고 중단 시 페이지별 캐시에서 재개합니다. 두 번째 명령은 로컬 `gulim.ttc`의 글자 모양과 PDF 내장 글꼴의 모양이 정확히 일치하는 경우에만 깨진 문자를 복원합니다. 글꼴이 없는 환경에서는 이 단계를 생략하고 OCR 참고 검색만 사용할 수 있습니다. 원본 또는 글꼴 버전이 다르면 기존 검증 결과를 그대로 적용하지 않습니다.

예: `와이퍼 배선도`, `와이퍼 모터 핀맵`, `레인센서 단자 기능`, `헤드램프 2-램프 핀맵`, `F102F 커넥터`.

원본 10쪽의 76개 표본 검사 항목이 보정 후 일치했습니다. 전체 문서의 모든 숫자·문자·연결 관계를 검증한 것은 아닙니다. OCR 자동 인식만으로 핀 연결이나 퓨즈 용량을 확정하지 않습니다. [OCR 검증 기록](docs/WIRING_OCR.md)을 참고하세요.

## 검증

```powershell
python scripts/run_tests.py
```

자동 테스트는 외부 연결을 모의 처리합니다. 실제 공식 API 연결은 별도 점검합니다. [검증 기록](docs/VALIDATION.md), [자료 검토 기준](docs/MANUALS.md), [구조·API](docs/DEVELOPMENT.md)를 참고하세요.

API 키 없이 실행하며 대화는 브라우저 메모리에만 유지됩니다. 원본 PDF, 추출 전문, 로컬 경로가 담긴 색인, 임시 이미지·로그는 Git에 포함하지 않습니다. 다른 PC에서는 허가된 PDF를 다시 가져와야 합니다. 서버는 루프백에서 실행하는 로컬 도구입니다.
